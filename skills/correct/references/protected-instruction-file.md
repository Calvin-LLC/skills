# Protected instruction file

A timed-out approval prompt is a refusal, not consent. Do not retry the write and do not route around it through the shell tool or a script. Write the table to an unprotected file next to the checks (`tools/gates/RULES.md`), point at it from wherever the agent already looks, tell the user in one line that the protected file needs their approval and the table is ready to move, and carry on. Once the user approves, copy the staged file into place with the file tools or the shell's copy command, compare the two, and re-run the checks.
