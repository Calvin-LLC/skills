### Worktree and simulator cleanup

**You own the disk and the safety gate.** Prune merged or abandoned git worktrees and (macOS only) stale iOS simulators to reclaim space. Deletion is irreversible, so every step guards against deleting something in use or holding uncommitted work.

1. Snapshot and audit. Record free disk space on the volume that holds the worktrees (POSIX `df -h <worktree parent>`; PowerShell `Get-PSDrive <drive letter>`). Take paths from `git worktree list --porcelain`, never hand-typed, since a hand-typed path misses worktrees an orchestration tool keeps elsewhere. Per worktree, record size (POSIX `du -sh <path>`; PowerShell `(Get-ChildItem <path> -Recurse -Force | Measure-Object Length -Sum).Sum`), age of HEAD, merged (`git merge-base --is-ancestor HEAD origin/main`; squash merges need the PR state from `gh pr list --state all --json number,state,headRefName`), uncommitted work (`git status --porcelain`: tracked edits are `wip:N`, untracked-only is `scratch:N`), and whether the branch is pushed. Suggest a bucket per row.
2. The bucket is advice, not permission. The pinned and active chats are the real artifact. Get that set from the user or the orchestration tool's worktree list and cross-check every candidate. A worktree that looks safe by git state can still be pinned, so the pinned set wins.
3. Verify usage before deleting. For every `verify-recent-chat` row, or anything you doubt, fan subagents out to read the transcripts (the **recall** skill: `python <recall skill dir>/scripts/sessions.py transcript --session <id>`) and report whether the chat is pinned or ongoing and which worktrees it touches (transcripts are bulk). A pinned chat spawns bakeoff and repro trees into sibling worktrees via background subagents, and those are in use even when their names never hit the sidebar.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits. Show the diff and get a decision first, since removing a clean worktree is recoverable from its branch but uncommitted work is gone. `scratch:N` is untracked throwaway, safe to drop, but name the files. Per Autonomy, clean and merged and not-in-use proceeds; `wip` and in-use pause.
5. Prune the confirmed set. Per path, `git worktree remove --force <path>`; if the dir survives on ignored build artifacts, delete it (POSIX `rm -rf <path>`; PowerShell `Remove-Item -Recurse -Force <path>`), then `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with the free-space check from step 1 and re-list.
6. Other reclaimers. **macOS only** (skip on Linux and Windows): simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes; also Xcode `DerivedData` and `iOS DeviceSupport`. Any OS: package caches (pnpm, uv, yarn, and brew on macOS/Linux). Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** free space before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in-use by which chat, or uncommitted work).
