# Scope and claims

- **Unrequested additions.** A convenience feature that replaces something already working is an unrequested product change. Asked "did you add other things?", table every addition against `git diff HEAD` and `git status` (item, file, asked for or extra), back up each file you will change, and remove the extras in the same turn.
- **Overturned figures.** When a later run overturns a figure or cause you reported, say which was wrong and why, correct the doc or commit text that carried it, and re-measure before building on it.
- **Pushback on a design.** "Feels random" or "inconsistent": quantify the spread with percentiles of the real distribution, not an average, before explaining. A corrected premise: rebuild the inputs from the real population's ranges.
